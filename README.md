# EduTalent — Sistem Asesmen Mandiri Minat & Bakat Siswa

EduTalent adalah aplikasi asesmen karakter berbasis Laravel untuk SMK Budi Karya Natar.
Dikembangkan menggunakan algoritma SPK Hybrid PM-SAW dan integrasi AI Gemini.

## Dokumentasi Lengkap
Lihat [BLUEPRINT_EDUTALENT.md](BLUEPRINT_EDUTALENT.md) untuk arsitektur sistem lengkap.

## Setup Lokal
```bash
composer setup
php artisan serve
```
